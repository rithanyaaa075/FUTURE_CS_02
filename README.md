# FUTURE_CS_02 – SIEM Security Alert Monitoring & Incident Response

## Objective
This task focuses on monitoring simulated security alerts using a SIEM approach, identifying suspicious activities from log data, classifying incidents, and preparing an incident response report.

The objective is to gain hands-on exposure to Security Operations Center (SOC) workflows such as log analysis, alert triage, and incident classification.

## Scope of Work
- Analyze sample security log files
- Identify suspicious activities and anomalies
- Classify incidents based on severity and impact
- Document findings in an incident response report

## Tools & Technologies
- SIEM concepts (Elastic Stack / Splunk – simulated)
- Sample log files (authentication, network, and system logs)
- Ubuntu Linux environment
- Manual log analysis techniques

## Skills Gained
- Log Analysis
- Alert Triage
- Incident Classification
- SOC Operations Basics
- Incident Response Documentation

## Deliverables
- Detected security alerts
- Incident classification details
- Incident response report with remediation recommendations

⚠️ All activities were performed on simulated logs in a controlled environment for educational purposes only.
